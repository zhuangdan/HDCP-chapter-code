# Saved results

This directory contains summary tables, simulation outputs, run metadata,
random seeds, and software session information from the completed analyses.
They allow users to compare a new run with the results reported in the chapter.

Three data-derived files are intentionally not tracked:

- `fred_md_transformed_balanced_panel.csv`
- `acgh_panel.csv`
- `acgh_figure_profiles.csv`

They are regenerated locally by `reproduce_fred_md.R`, `reproduce_acgh.R`,
and `plot_acgh_figure.R`.
